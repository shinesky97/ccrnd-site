# 감사조서 체크리스트 및 파일 매핑표

법인 표준 조서 양식(일반조서·계정별조서·정산표) 분석에 기반한 정본 매핑이다.
파일명 또는 내용(시트명·제목행)에서 아래 조서번호/키워드가 확인되면 해당 항목의 근거로 분류한다.

## 1단계: 위험평가·감사계획 (일반조서 전반부)

## 상태 판정 시 주의

- 하나의 파일이 여러 항목의 근거가 될 수 있다 (예: 일반조서 통합파일 1개에 1100~8600 시트 전부).
  이 경우 Index 시트의 작성자/검토자 기재를 조서번호별로 읽어 개별 판정한다.
- 정산표 파일(8600A)의 시트 구성 예: AR(정산표), SAD(수정분개 요약), dsd(공시 BS),
  CF(현금흐름표), FN(주석), 명세류. AR에 당기 수치가 채워져 있으면 3단계 진행,
  SAD에 수정분개가 정리되어 있으면 8100 근거로도 분류.
- 검토자·심리(8600C)·서명본(8300A, 8600B)은 보고서 발행의 하드 게이트이므로
  미확인 시 4단계를 "완료"로 표시하지 않는다.
