# kgaapaudit — K-GAAP 감사 진행현황 점검

## 목적

현재 작업 폴더(감사자료 폴더)의 파일들을 근거로, 표준 감사 흐름 4단계 대비
**어디까지 진행되었고 무엇이 남았는지**를 판정하여 자체완결형 HTML 리포트로 보여준다.

## 절대 원칙 (위반 금지)

1. **근거 없는 완료 표시 금지.** 폴더의 파일에서 확인된 것만 "완료/진행중"으로 표시한다.
   파일이 없으면 추측하지 말고 "미착수 또는 자료 미제출 — 담당자 확인 필요"로 표시한다.
2. **파일 존재 ≠ 감사판단 완료.** 조서 파일이 있어도 검토·승인까지 되었다고 단정하지 않는다.
   작성자/검토자 기재 여부를 확인하고, 검토자가 비어 있으면 "작성됨(검토 미확인)"으로 표시한다.
3. **원본자료를 수정하지 않는다.** 모든 파일은 읽기 전용으로만 연다. 산출물(HTML)은 새 파일로 만든다.
4. **개인정보 비노출.** 리포트에 주민등록번호·계좌번호 등을 옮겨 적지 않는다.
   (거래처명·금액 등 감사자료 수준 정보는 표시 가능)

## 수행 절차

### 1단계: 폴더 스캔

현재 폴더(및 하위 폴더)의 파일 목록을 수집한다. 대상: xlsx/xls, pdf, docx, hwp, csv 등.
파일명과 (엑셀인 경우) 시트명·주요 셀 내용을 읽어 각 파일을 분류한다.
엑셀은 `openpyxl` `read_only=True, data_only=True`로 연다. 대용량 시트는 상단 일부만 읽는다.

### 2단계: 파일 분류 — 조서번호 체계 기반

분류 기준은 `references/wp-checklist.md`의 매핑표를 따른다. 핵심 체계:

| 조서번호 | 영역 | 단계 |
|---|---|---|
| 1100~1300 | 수임·독립성 | 1단계 |
| 2100~2700 | 감사계획·위험평가·중요성 | 1단계 |
| 2511~2530, 2600 | 내부통제 이해·워크스루·통제테스트 | 2단계(중간감사) |
| 3100~3800 | 위험대응·특이거래·추정치·특관자·부정 | 2단계(중간감사) |
| 4000 계열 (A~CF 알파벳 인덱스) | 계정별 입증감사절차 조서 | 3단계(기말감사) |
| 조회서·명세서·실사 자료 | 입증절차 근거자료 | 3단계 |
| 8100~8600 | 왜곡표시평가·종결절차·정산표·발행 | 4단계 |

조서번호가 파일명에 없으면 **내용으로** 판별한다(시트명 Index/입증감사절차/AR/SAD,
문서 제목 행 등). 판별이 안 되는 파일은 "미분류"로 리포트 하단에 나열한다.

### 3단계: 양식 vs 작성본 구분 (중요)

양식(템플릿)만 있는 것은 진행으로 치지 않는다. 다음 신호로 구분한다:

- **작성본 신호**: 실제 회사명(예: "주식회사 ○○"), 당기 결산일(당해 연도), 작성자·작성일에
  실명·실제 날짜 기재, 수치 데이터 채워짐.
- **양식 신호**: 회사명 비어 있음/샘플명, 예시 담당자(예: "홍길동"), 오래된 예시 날짜,
  수치 대부분 공란.

Index 시트가 있으면 조서번호별 작성자/작성일/검토자/검토일 열을 읽어
**조서 단위**로 상태를 판정한다 (작성자만 있음 → 작성됨·검토 미확인, 둘 다 있음 → 검토됨).

### 4단계: 단계별 진행률 판정

`references/wp-checklist.md`의 체크리스트 항목별로 상태를 부여한다:

- `DONE` 검토까지 확인됨 (작성자+검토자 기재 또는 완결 문서)
- `PREPARED` 작성됨, 검토 미확인
- `IN_PROGRESS` 부분 작성 / 근거자료만 수령
- `NOT_FOUND` 폴더에서 확인 불가 (미착수 또는 자료 미제출 — 단정하지 않음)
- `N/A` 해당 없음이 명백한 경우만 (예: 초도감사 아님이 확인되면 3800)

단계 진행률(%) = (DONE×1.0 + PREPARED×0.7 + IN_PROGRESS×0.3) ÷ 해당 단계 항목 수.
N/A 항목은 분모에서 제외. 리포트에 이 계산식을 명시한다.

### 5단계: HTML 리포트 생성

자체완결형(외부 리소스 없음) HTML 한 개를 현재 폴더에 `감사진행현황.html`로 저장한다.
구성 (위→아래):

1. **헤더**: 회사명·결산일(자료에서 파악된 경우만), 점검 기준(폴더 경로, 파일 수), 생성일시
2. **4단계 플로우차트** (가로 배치, CSS로 그림):
   `[1] 위험평가·감사계획 → [2] 중간감사 → [3] 기말감사 → [4] 보고서 발행`
   각 박스에 진행률 %와 색상 — 완료(≥90%) 녹색, 진행중(30~89%) 노란색,
   착수(1~29%) 주황색, 미착수(0%) 회색. 박스 아래에 단계 요약 한 줄.
3. **단계별 체크리스트 표**: 조서번호 | 절차명 | 상태 | 근거 파일(파일명) | 비고.
   상태는 색상 배지로 표시.
4. **남은 절차** 섹션: NOT_FOUND·IN_PROGRESS 항목을 실무 순서대로 나열하고,
   각 항목에 "필요한 자료/행동"을 한 줄씩 제안.
5. **확인 필요** 섹션: 미분류 파일, 판단이 모호했던 항목, 검토자 미기재 조서.
6. **푸터 고지**: "본 리포트는 폴더 내 파일의 존재·기재 상태만을 근거로 한 진행현황
   참고자료이며, 감사절차의 완료 여부에 대한 감사판단을 대체하지 않습니다."

한국어, 프로페셔널한 스타일(시스템 폰트, 표 중심), 밝은 배경. 생성 후 사용자에게
파일을 전달(SendUserFile 가능 시 render로)하고, 터미널에도 단계별 진행률과
남은 절차 상위 5개를 요약해 보여준다.
