# 감사 방법론 (Audit Methodology)

- 버전: 1.0 · 기준일: 2026-07-30
- 적용 기준: 대한민국 회계감사기준(ISA 기반), 일반기업회계기준(K-GAAP) 기본

이 문서는 시스템이 구현하는 감사절차의 방법론적 정본이다. 여기의 모든 "자동 계산·제안"은
회계사 승인 게이트(human-review-policy.md)를 통과해야 효력을 가진다.

계정별 위험평가와 절차 설계는 다음 8개 주장 기준으로 수행한다.

| 코드 | 주장 | 주 적용 |
|---|---|---|
| E/O | 실재성 또는 발생사실 | 자산·수익 |
| C | 완전성 | 부채·비용 |
| A | 정확성 | 거래·잔액 |
| CO | 기간귀속 | 결산 전후 거래 |
| CL | 분류 | 계정 분류·유동성 |
| R&O | 권리와 의무 | 자산·부채 |
| V | 평가와 배분 | 추정치·충당금 |
| P&D | 표시와 공시 | 재무제표·주석 |

## 3. 중요성 (확정 공식)

```
전체 중요성(OM)       = (자산총액 + 매출총액) ÷ 2 × 1%          # 발주자 확정 기본 공식
수행중요성(PM)        = OM × 75%   (기본 제안. 위험 높으면 50~60%로 하향 제안)
명백히 경미한 기준(CT) = OM × 5%    (기본 제안)
특정 중요성           = 특정 계정·공시에 대해 별도 입력 가능
```

- 시스템은 매출액·세전이익·총자산·순자산 등 참고 기준별 계산값도 병렬 표시한다(비교 목적).
- 어떤 값도 자동 확정되지 않는다. Partner 승인 전에는 후속 절차(중요계정 식별, 표본 계산,
  감사차이 평가)가 시작되지 않는다.
- 기중 수정 시 새 버전 생성 + 기존 절차에 대한 영향 재평가 플래그.

**중요계정 자동 식별 규칙**: 계정 잔액 또는 거래총액 ≥ PM → 중요계정 후보.
질적 요인(추정 개입, 특수관계자, 과거 오류 등)은 AI가 후보 사유로 제안하고 회계사가 확정.

## 4. 위험평가

- 재무제표 수준 위험과 주장 수준 위험을 분리 관리.
- 위험 레코드 필드: risk_id, 계정과목, 관련 주장, 위험 설명, 발생 근거, 고유위험, 통제위험,
  유의적 위험 여부, 부정위험 여부, 관련 내부통제, 계획된 감사대응, 필요한 감사증거,
  담당자, 검토자, 상태.
- 기본 부정위험 전제: **수익인식 부정위험 추정**(감사기준 240 정합)과 **경영진의 통제 무력화** 위험은
  시스템이 기본 후보로 항상 생성하며, 배제 시 사유 입력을 요구한다.
- AI는 후보 제안까지. 유의적 위험·부정위험 최종 지정은 Partner 승인.

## 5. 분석적 절차 (결정적 엔진)

당기↔전기 비교 / 월별·분기별 추이 / 예산 대비 실적 / 계정 간 비율 / 매출총이익률·영업이익률·회전율 /
거래처별 집중도 / 월말·연말 비정상 거래 / 급증·급감 계정 / 음수·비정상 잔액 / FS↔원장 불일치 /
반대계정·상계 가능성 / 정수·반복 금액·비정상 설명 분개 / 휴일·비업무시간 분개 / 결산일 전후 거래

각 이상항목 기록 필드: 금액, 중요성 대비 비율, 탐지규칙 ID, 원천자료 참조, 제안된 추가 감사절차.

**기본 임계값 (미결 — 확정 전 제안 기본값, 설정으로 조정)**

| 규칙 | 기본값 |
|---|---|
| 급증·급감 플래그 | 전기 대비 ±30% 이상 그리고 변동액 ≥ CT |
| 결산일 전후 거래 | 결산일 ± 15일 |
| 비업무시간 | 22:00~06:00, 주말, 법정공휴일(한국 공휴일 테이블) |
| 정수 금액 | 백만원 단위 이상의 000,000 배수 |
| 반복 금액 | 동일 금액 5회 이상 반복 |

## 6. 이상분개 탐지 규칙 (Journal Entry Testing)

규칙 엔진(je_anomaly_rules)은 규칙 ID·버전을 가진 결정적 규칙의 집합이다. 초기 규칙:

JE-01 차대 불일치 / JE-02 중복 분개(동일 일자·계정·금액·적요) / JE-03 결산일 전후 수익 인식 /
JE-04 휴일·비업무시간 입력 / JE-05 정수·반복 금액 / JE-06 비정상 적요(공란, "조정", "임시" 등 사전) /
JE-07 드문 계정 조합(예: 매출 ↔ 현금 외 상대계정) / JE-08 승인자=입력자 동일 /
JE-09 기말 대액 수동분개 / JE-10 음수·역분개 패턴

모든 탐지 결과는 근거(gl_entries 행 참조)와 함께 anomalies에 저장되고, 중요성 대비 비율을 계산한다.

## 7. 표본선정 (Claude 추천안 — 발주자 위임에 따른 채택안)

### 7.1 세부테스트 (비통계적 보증계수 방식, MUS 개념 기반)

```
1) 개별중요항목 전수선정: 항목 금액 ≥ PM, 또는 질적 중요 항목(특수관계자 등)
2) 잔여 모집단 표본 수:
   n = ceil( 잔여 모집단 금액 ÷ (PM − 기대왜곡표시) × 보증계수 )
3) 하한 = 10, 층화(금액 구간별) 옵션 제공
```

**보증계수 표** (위험평가 결합수준 × 기타 실증절차 의존 여부):

| 중요왜곡표시위험 | 기타 실증절차 병행 | 보증계수 |
|---|---|---|
| 유의적 위험 | 아니오 | 3.0 |
| 높음 | 아니오 | 2.3 |
| 높음 | 예 | 1.8 |
| 중간 | 아니오 | 1.5 |
| 중간 | 예 | 1.0 |
| 낮음 | 예 | 0.5 |

근거: AICPA Audit Sampling Guide의 비통계적 표본 산식과 실무 관행을 준용. MUS(금액단위표본)로
확장 가능하도록 동일 파라미터 구조(모집단·허용왜곡·기대왜곡·위험계수)를 사용한다.

### 7.2 통제테스트

발생빈도 기반 최소 표본 표(관행 준용): 연 1회=1, 분기=2, 월=2~5, 주=5~15, 일 다수(자동 반복)=25~60.
편차 발견 시 확대 또는 통제 비의존 전환을 제안.

### 7.3 공통 규칙

- 모집단 완전성: 모집단 합계 ↔ 총계정원장 잔액 대사가 통과해야 표본추출 가능.
- 방법: 전수 / 목적표본(위험조건) / 무작위 / 계통 / MUS(확장).
- seed 저장으로 재현 가능. 표본 제외 시 사유 기록 필수.
- **시스템은 표본 수를 자동 확정하지 않는다.** 위 산식은 추천안이며 Manager 이상 승인 필수.

## 8. 감사차이 평가

- 분류: 사실왜곡 / 판단왜곡 / 추정왜곡.
- 개별 및 누적(미수정왜곡표시 합계) 영향을 OM·PM 대비 비율로 자동 계산.
- 수정분개 목록과 미수정왜곡표시 요약표(SUM)를 자동 생성.
- 누적 미수정왜곡 ≥ PM → 경고, ≥ OM → 보고서 초안 생성 차단 + Partner 평가 필수.
- 질적 중요성(추세 전환, 약정 위반 유발 등)은 AI가 검토 포인트로 제안, 결론은 Partner.

## 9. 완료절차 체크리스트 (기본안 — 법인 정책 반영 예정)

미해결사항 0건 확인 / 최종 분석적 절차 / 후속사건 / 계속기업 / 특수관계자 완전성 / 우발부채 /
법률조회 / 경영진확인서 수령·일자 확인 / FS↔주석 최종 대사 / 감사차이 누적평가 /
표시·공시 체크리스트 / 작성자·검토자·업무책임자 3단계 승인

전 항목 통과 전 감사보고서 초안 생성이 차단된다 (report-generation-policy.md).
