# 감사보고서 생성 정책 (Report Generation Policy)

- 버전: 1.0 · 기준일: 2026-07-30

## 1. 원칙

- 시스템은 감사보고서의 **초안**만 생성한다. 최종 의견 확정과 보고서 발행은 시스템 밖의
  회계사(업무책임자) 행위이다.
- **의견 필드에는 기본값이 없다.** `opinion_type`이 NULL이면 초안 생성 자체가 불가하다.
- AI에는 의견 필드에 대한 쓰기 경로가 코드 레벨에서 존재하지 않는다. AI 출력 스키마에도
  의견 필드가 없다.
- 보고서 문구는 (감사기준 정합) 템플릿 + 구조화된 감사결론 데이터로 조립한다.
  발견사항만으로 의견을 임의 결정하지 않는다.

## 2. 지원 보고서 구조

- 의견 유형: 적정 / 한정 / 부적정 / 의견거절
- 부가 문단: 강조사항, 기타사항, 계속기업 관련 문단
- 핵심감사사항(KAM): 확장 가능한 구조(JSONB)로 설계, 초기 버전 UI는 미제공

## 3. 생성 전 필수 게이트 (모두 충족해야 초안 생성)

1. 완료 체크리스트(completion_checklist) 전 항목 통과 — 미해결사항 0건 포함
2. 누적 미수정왜곡표시 평가 완료 (≥ OM이면 Partner 평가 없이는 차단)
3. 필수 입력값 전부 존재:
   - 적용 재무보고기준 (기본: 일반기업회계기준)
   - 적용 감사기준
   - 감사대상 재무제표 목록, 재무제표 기준일, 감사대상 기간
   - 경영진 책임 문구 / 지배기구 책임 문구 / 감사인 책임 문구
   - **선택된 감사의견** (명시적 선택, 기본값 없음)
   - 의견변형 시: 변형 근거 (구조화된 감사차이·범위제한 참조 필수)
   - 강조사항·기타사항 (해당 시)
   - 감사보고서일, 감사인 정보
4. **업무책임자(Partner) 최종 승인** — approvals에 사유와 함께 기록

## 4. 의견-근거 정합성 검사 (경고, 확정은 하지 않음)

시스템은 다음 불일치를 **경고**로 표시하되, 의견을 변경하거나 확정하지 않는다.

- 적정의견 선택 + 누적 미수정왜곡 ≥ OM → 경고 및 Partner 재확인 요구
- 계속기업 중대한 불확실성 결론 존재 + 관련 문단 누락 → 경고
- 한정/부적정 선택 + 변형 근거 미연결 → 생성 차단 (근거 없는 변형의견 불가)

## 5. 버전·이력

- 보고서 초안은 버전 관리되며, 승인 후 변경은 새 버전 + 재승인.
- 초안 생성에 사용된 템플릿 버전, 구조화 결론 참조, 생성 시각을 기록한다.
